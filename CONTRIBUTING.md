# Contributing and scientific review

The programme welcomes reproducibility questions, identified errors, careful conventional-model comparisons and suggestions for independent tests. Open a GitHub issue that names the evidence number (**WN-nn**) and, where relevant, the Chapter 15 result (**Un**), or propose a pull request with a documented source and reason for the change.

Please distinguish reproducible checks from interpretations. A released public edition is not edited in place: a correction is made as a new revision, recorded in [tc/ch15/PREPARATION.md](tc/ch15/PREPARATION.md) and in a new tagged release, and the earlier release stays available. A documentation edit must not promote a speculative result to verified status. Changes to the evidence need the author's explicit approval.

Do not upload third-party copyrighted material, confidential datasets or personal information.
