# Contributing and scientific review

The programme welcomes reproducibility questions, identified errors, careful conventional-model comparisons and suggestions for independent tests. Open a GitHub issue referencing a specific **WN** and **U** identifier where possible, or propose a pull request with a documented source and reason for the change.

Please distinguish reproducible checks from interpretations. Do not replace an original unpublished note or promote a speculative result to verified status through a general documentation edit. Proposed changes to the evidence archive require explicit author approval and a versioned review record before acceptance.

Do not upload third-party copyrighted material, confidential datasets or personal information.
