# Evidence packages

No WN source files are released in the repository yet. The first planned scope is the Technical Companion Chapter 15 evidence series, using stable identifiers `WN-01`–`WN-44` plus the character-repaired companion `WN-26R`.

On approval, each WN package should occupy `evidence/TC-Ch15/WN-XX/` and include a readable note, `STATUS.md`, and links to supporting verification/corrections when available. No empty placeholder notes should be mistaken for released scientific evidence.

For the current inventory see [TC Chapter 15 catalogue](../registers/TC_CH15_WN_catalogue_v0.md).
