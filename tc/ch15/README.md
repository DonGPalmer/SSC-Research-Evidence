# Technical Companion Chapter 15: evidence register (U1–U18)

*Revision 3, 20 Nov 2026: public editions, first released as v1.0.0 of this repository.*

Chapter 15 cites each unpublished result (U1–U18) to evidence numbers WN-01 to WN-44. This register says what each numbered note is, what role it plays for the result, how far it has been reviewed, and exactly which file it is.

**A citation shows where a result came from. It does not show that the result is correct.** A note listed here may give an initial calculation, a correction, a check, a contrary result or a decision not to adopt a proposal; it is not necessarily evidence for the whole claim. None of these notes has a DOI or has had external scientific review. They are released as public editions: the working text with internal paths and workflow lines removed and later corrections flagged, and with the mathematics unchanged. [PREPARATION.md](PREPARATION.md) records every edition's changes and hashes.

## How to read this register

- **Evidence number (WN-nn):** stable citation used in Chapter 15. Numbers are fixed; a moved or renamed note keeps its number and gets a new file row in a later version of this register.
- **Role:** *derivation* (a calculation that produces the result); *check* (a test of a claim or rule); *counter-result* (a calculation that goes against a claim); *correction* (amends an earlier note); *decision* (records a choice to retain, hold or stop); *proposal* (a draft rule or wording, not adopted); *analysis* (sets out a choice without deciding it); *internal review* (an AI review made in a separate session within the programme).
- **Review status:** taken from each note's own status line. *Unreviewed AI calculation* means a calculation drafted with AI assistance and not reviewed. *AI-assisted, separate session* means work done in an AI session separate from the WS1 working notes; it is not an external review. *Revised after an AI-assisted review* means amended after a check by another AI session within the programme, not an external review.
- **Responsible researcher:** Donald G. Palmer, for all notes. All were drafted with AI assistance, as each note's own status line records.
- **Access:** the public editions of WN-01 to WN-44 are in this repository, first released as v1.0.0. Source identities, editorial changes and file hashes are documented in [PREPARATION.md](PREPARATION.md).
- **Licence:** CC BY 4.0 (see the repository's LICENSE).
